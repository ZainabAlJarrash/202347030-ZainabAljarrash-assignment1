# Zainab Aljarrash – Personal Portfolio

A responsive personal portfolio website created for Assignment1 in SWE363 .

The website introduces me, presents my projects and interests, and provides ways to contact me.

## Features

- Responsive design for desktop, tablet, and mobile.
- About Me section.
- Two project cards with images and descriptions.
- Skills and interests section.
- University email and LinkedIn links.
- Contact form with validation and feedback.
- Greeting based on the time of day.
- Light and dark themes.
- Saved theme preference.
- Automatic copyright year.

## Projects

### Seraj

A virtual reality game designed to introduce users to Saudi culture through an interactive experience.

### Networking Assistant

A project designed to help students understand information related to computer networks.

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.

Note : No installation or backend is required.
